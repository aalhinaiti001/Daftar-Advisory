Turn 01 · Mark exploration

Four symbol directions for Daftar Advisory.

PwC and EY both run a fixed symbol plus a flat wordmark, one accent colour, no gradient. Same construction here — ink mark, ink wordmark, rust as the 5%. Each direction below is a different argument for what the symbol should mean.

Note — the handbook currently says the wordmark is the logo and there is no symbol. Adding one is a deliberate deviation.
