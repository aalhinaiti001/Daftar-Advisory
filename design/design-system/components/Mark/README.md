The Daftar mark is the folded file: an ink page with its corner turned down in rust (`rust`). Use it on every Daftar surface; it replaces the retired D monogram.

- Use the Standard cut (fold 64/36) at 24px and up: `assets/Marks/daftar-mark.svg`.
- Use the Small cut (fold 54/46) below 24px: `assets/Marks/daftar-mark-small.svg`. Never go below 16px.
- Keep clear space equal to the fold height on every side: 0.32 of the width in the Standard cut, 0.42 in the Small.
- On ink the page becomes `paper` and the corner stays `#A8341F`: `assets/Marks/daftar-mark-on-ink.svg`.
- Never drop or recolour the corner, stretch, rotate, outline, add a gradient or a shadow, or use the Small cut large or the Standard cut small.
- The consumer provides the surface colour behind the mark; the SVG files are single-file, fixed-colour artwork.
