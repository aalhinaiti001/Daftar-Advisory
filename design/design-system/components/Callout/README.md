A callout holds one idea on `card` with a `hairline` `rule` border and `radius-md`. Its label is mono in `ink`; its text is `body`.

- Use it for a position, a note on how to read a document, or the non-attest notice (on `soft`).
- No shadow, no left-border accent, no rust fill.
- The consumer provides one short label and one or two sentences.
