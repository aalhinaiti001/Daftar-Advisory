A placeholder is square-bracketed text on `soft` with `radius-sm`; a slot is the block version on `soft` with a `rule` border and a mono label.

- Use one for every fact not yet supplied: a name, date, figure, credential, service name. Never invent the fact.
- Delete the brackets and the band when the fact is confirmed.
- Placeholders are working marks, not brand elements: remove them all before a document is issued.
