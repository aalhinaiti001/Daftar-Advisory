Tables are ruled, not shaded: a 1px `ink` rule under the mono header row, 1px `rule` between rows, tabular lining numerals throughout.

- Headers are mono, uppercase and `muted`; cells are `body`; the total row is `ink` between two ink rules.
- Right-align numbers (left in RTL). Left-align Latin text; right-align Arabic.
- The consumer provides the columns and the data. Never use zebra fills, shadows or coloured headers.
