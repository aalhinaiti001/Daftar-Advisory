A section band separates sections without shadow. Use `soft` between two `rule` hairlines for alternate sections.

- An ink section (`ink` ground, `paper` text, `body-on-ink` running text, `muted-on-ink` labels, `rust-on-ink` accent) is allowed once per page.
- Never invert the ratio: paper 70, ink 25, rust 5.
- The consumer provides the content; keep text at 4.5 : 1 or better on the band's ground.
