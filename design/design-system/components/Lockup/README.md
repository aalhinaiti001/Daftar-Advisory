A lockup pairs the mark, a 1px `rule` hairline and the wordmark “Daftar Advisory.” with “Advisory.” in rust italic.

- Horizontal is the default and is required on letters, statements and brochures: `assets/Marks/daftar-lockup-horizontal.svg`.
- Stacked is for square formats. The micro strip, “Daftar · Advisory” in mono, is for post headers. The Arabic lockup is “دفتر للاستشارات.” with the accent word in `rust` at weight 500.
- On ink, “Advisory.” switches to `rust-on-ink` and the mark is knocked out: `assets/Marks/daftar-lockup-horizontal-on-ink.svg`.
- The lockup SVGs have outlined text, so they need no font. The consumer chooses the size; keep the mark at 24px or more.
- Never set the wordmark in another face, and never set “Advisory.” in `rust` on ink.
